## Python dependency audit

The documented PyPI-backed `pip-audit -r requirements-dev.txt` did not return within several minutes on this connection. The completed local audit, `pip-audit --local --vulnerability-service osv --timeout 30 --progress-spinner off`, exited 1 and reported 40 records across two packages: `pip 25.0.1` and `PyJWT 2.13.0`. The audit output listed fixes up to `pip 26.2.0` and `PyJWT 2.15.0`; some vulnerability IDs were repeated in the output.

## Browser test adjustment

The first sign-in browser runs found that `getByLabel('Password')` also matched the nested “Show password” button. Both browser specs now target the password input by its `name` attribute. The affected browser specs passed when rerun, and ESLint passed afterward.
